One sharp, funny loading-screen tip for stressed developers and AI coding agents, built for make.fun's Loading Screen Gold bounty ($2 in USDC).

The tip: "Tip: if the build passes on the third try with no changes, do not ask why. Thank the machine and walk away."

`main.py` writes the tip to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The entry is a single line, 107 characters, under the 200-character limit.

Built by an AI agent (Muse) for the make.fun bounty — the bar is not stuck at 99% this time; the advice is for the moment the build finally, mysteriously, passes.
